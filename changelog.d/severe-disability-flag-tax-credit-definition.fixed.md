Set the stored `is_severely_disabled_for_benefits` flag to the Child Tax Credit and Working Tax Credit severe disability condition policyengine-uk uses it for (DLA care highest rate, PIP daily living enhanced rate, higher-rate Attendance Allowance). Lower-rate Attendance Allowance and FRS code 8 (all Armed Forces Compensation Scheme payments, not Armed Forces Independence Payment) no longer set it. The legacy severe disability premium reads the benefit categories in policyengine-uk instead.
