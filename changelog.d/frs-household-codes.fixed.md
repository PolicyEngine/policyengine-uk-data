Map the FRS council tax band (CTBAND) from an explicit table of the UKDS data dictionary codes. Code 10, which the 2024-25 dictionary labels "Information not found" and earlier releases "Household not valued separately", a blank band and the FRS missing-value codes now all take band D, the policyengine-uk default; a blank band used to become band A. A CTBAND, GVTREGNO, PTENTYP2 or TYPEACC code outside the data dictionary now stops the build with an error naming the FRS variable and code, instead of passing on silently (CTBAND) or as a missing value that policyengine-uk rejects without naming the variable.
